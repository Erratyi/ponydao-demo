# PonyDAO 当前 MVP 演示版

独立于 `../mvp` 与旧 `../demo`，保留当前 DAO 市场、跨 DAO 工作台/分账台、DAO 详情及左下角账户入口。不需要登录，不连接任何真实 API、数据库或支付服务。

## 打开

```bash
cd ponydao-demo
npm ci
npm run build
npm start
```

访问 http://127.0.0.1:3200 。正式 MVP 仍使用 3100，互不影响。后续修改界面可使用 `npm run dev`；不要同时占用相同端口。

## 推荐演示顺序

1. DAO 中心：搜索、筛选、进入 PONYGOGO 查看产品、项目与治理。
2. 顶部切换“研发”：查看参与、成果与收益。切换“管理员”确认待审批成果。
3. 分账台：查看跨 DAO 收益来源，进入 DAO 金库生成分账草稿；切换“财务审核”发布，演示双人审核。
4. 治理提案：切换五个角色分别投票，全部投完后结算，再由管理员执行。
5. 点击“重置演示”恢复初始数据；左下角“重新体验”也会重置。

所有金额、成员、项目进度和凭证均为虚拟示例。操作只保存在当前浏览器的 localStorage，不会同步给其他人。邀请仅创建虚拟待审批成员，不发送邮件；附件仅在浏览器计算摘要并保存文件信息，不上传文件内容；下载返回演示说明而非原文件。请勿填写真实账号或敏感信息。

## 分享准备

`out/` 是可独立部署的纯静态网页。没有 `.env`、数据库、服务器 API、管理员密码或业务数据。不直接双击 HTML，请使用 HTTP 服务。

GitHub Pages 发布地址：https://erratyi.github.io/ponydao-demo/ 。仓库的 Settings → Pages 使用 GitHub Actions；推送 main 后自动测试、构建与部署。

GitHub Actions 使用 `NEXT_PUBLIC_BASE_PATH=/ponydao-demo` 构建子路径版本；本地 `npm run build` 不设置该变量，继续使用根路径。Logo、页签图标和浏览器导航共用该配置。

## 检查与更新

`npm test` 检查演示数据、角色权限、投票、成果、分账、提现和重置；`npm run build` 进行类型检查和静态导出。本次未执行浏览器点击或截图测试。

提供可选 WebMCP 读取目录/打开 DAO 的两个入口，不支持时自动忽略；当前环境未验证其浏览器注册行为，不影响正常手动演示。
